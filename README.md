# 🚀 Modern Personal Portfolio Website

A sleek, fully responsive, and interactive personal portfolio website designed to showcase skills, experience, and creative projects. Built with a modern dark theme and striking red accents, this website is optimized for both desktop and mobile viewing.

## ✨ Features

* **Modern Dark UI:** A professional and clean dark aesthetic (`#080e20`) that makes images and portfolio work pop.
* **Interactive 'About' Tabs:** Uses Vanilla JavaScript to seamlessly toggle between Skills, Experience, and Education without reloading the page.
* **Fully Responsive Design:** Adapts perfectly to any screen size. Features a custom animated sliding side-menu for mobile users.
* **Working Contact Form:** Integrated with Web3Forms to receive emails directly from the website without needing a backend server.
* **Dynamic CSS Grid Layouts:** Beautifully structured grid systems for the 'Services' and 'Portfolio' sections, complete with smooth hover animations and image overlays.
* **Custom Typography:** Utilizes Google Fonts (Mulish, Science Gothic) for a highly polished, readable typographic hierarchy.

## 🛠️ Technologies Used

* **HTML5:** Semantic markup and structured content.
* **CSS3:** Advanced styling, CSS Grid, Flexbox, media queries for responsiveness, and smooth transition animations.
* **Vanilla JavaScript:** DOM manipulation for the interactive tab system and mobile navigation menu.
* **Web3Forms API:** Real-time form submission handling.

## 🚀 How to Run Locally

Since this project uses pure Vanilla JavaScript, HTML, and CSS, it is incredibly easy to run.
